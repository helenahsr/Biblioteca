# Sistema de Biblioteca
O Sistema de Biblioteca é uma aplicação desenvolvida em Java para gerenciar o acervo de livros, controle de empréstimos e devoluções, além do cadastro de usuários. O objetivo é facilitar a administração de bibliotecas, oferecendo uma interface intuitiva e eficiente.

## Funcionalidades
- Cadastro e gerenciamento de livros
- Registro de empréstimos e devoluções
- Controle de prazos
- Cadastro de usuários e histórico de empréstimos

## Tecnologias utilizadas
- Java (Swing)
